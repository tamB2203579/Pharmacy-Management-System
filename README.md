# Pharmacy Management Sytem

The Pharmacy Management System is a comprehensive application designed to streamline and automate the operations of a pharmacy. Developed using Java and MySQL, this system offers features such as inventory management, sales processing, and reporting to enhance efficiency and accuracy in managing pharmaceutical activities.

## Features
- **Inventory Management**: Maintain detailed records of all medicines, including stock levels, expiry dates, and supplier information.
- **Sales Processing**: Efficiently handle sales transactions with invoice generation and sales tracking.
- **Reporting**: Generate comprehensive reports on sales, inventory status, and other critical metrics to aid decision-making.

## Technologies Used
- Frontend: JavaFX
- Backend: Java
- Database: MySQL
- Build tool: Maven

# Installation and Setup
1. Clone the Repository:

   ```
   git clone https://github.com/tamB2203579/Pharmacy-Management-System.git
   cd Pharmacy-Management-System
2. Database Setup:
- Ensure you have MySQL installed and running.
- Create a database named pharmacy.
- Import the provided `pharmacy.sql` file to set up the necessary tables.
3. Configure database connection: Update the database connection settings in the `database.java` file to match your MySQL credentials.
4. Build and Run the Application: Use IntelliJ IDE to build and run the project.
# Usage
Upon launching the application, you will be prompted to log in. After authentication, you can access various modules to manage inventory, process sales, and generate reports.
