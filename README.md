# Pharmacy Management Sytem

The Pharmacy Management System is a comprehensive application designed to streamline and automate the operations of a pharmacy. Developed using Java and MySQL, this system offers features such as inventory management, sales processing, and reporting to enhance efficiency and accuracy in managing pharmaceutical activities.

## Features
- **Inventory Management**: Maintain detailed records of all medicines, including stock levels, expiry dates, and supplier information.
- **Sales Processing**: Efficiently handle sales transactions with invoice generation and sales tracking.
- **Reporting**: Generate comprehensive reports on sales, inventory status, and other critical metrics to aid decision-making.

## Technologies Used
- Frontend: JavaFX
- Backend: Java
- Database: MySQL
- Build tool: Maven
